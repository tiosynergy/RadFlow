## 4. ПРАВИЛА, КУПЛЕННЫЕ ДОРОГО (не переоткрывать)

1. **Секреты и ПИИ — НИКУДА.** Ни в отчёт, ни в лог, ни в промпт субагента.
   Прод-данные — только явным списком id с образами «до»; образ **редактируется**,
   если строка несёт секреты (0197 намеренно НЕ писал `to_jsonb(auth.users)` —
   там хеш пароля и почта).
2. **«Сухой» прогон БЕЗ маркера отката — это НАКАТ.** `execute_sql` гонит
   многостейтментный батч ОДНОЙ транзакцией. Заканчивай зонд
   `raise exception 'PROBE_OK …'` — он и откатит, и вернёт замеры.
3. **«Успешно» — не доказательство.** После каждого наката проверяй ОТДЕЛЬНЫМ
   запросом. Откат, проверенный внутри той же транзакции, не доказывает ничего.
4. **Два независимых источника времени.** `timeout /t N` через мост Desktop
   Commander **молча не спит** (stdin перенаправлен). Используй
   `Start-Sleep` и **печатай время пробуждения**. ⚠️ И: `read_process_output`
   **возвращается раньше таймаута** — считать свои опросы за минуты НЕЛЬЗЯ
   (в с72 я так «насчитал» шесть минут вместо 91 секунды). Сверяйся с
   `Get-Date` и `StartTime` процесса.
5. **Не трогай дерево, пока идёт стенд.** Полная ревизия — ~53 минуты. Если
   всё же остановил — **немедленно** сверь дерево: убитый стенд не выполняет
   `finally` и оставляет мутации (в с69 и в с72 — оба раза). `git status` →
   `git checkout --` → останови живые `node` → сними `.falsify-all.running` →
   `npm run db:gate:check` как доказательство побайтного восстановления.
6. **Контрольным суммам — место в гейте, а не в vitest.** Сумма по всему телу
   стреляет на любой косметике и ломает ПОЗИТИВНЫЕ контроли стендов (в с72
   покраснели `falsify-0180` и `falsify-0181`). Стендам нужен набор, который
   молчит на рефакторе.
7. **Пункт очереди — это ГИПОТЕЗА, а не факт.** В с71 замер показал, что
   половина постановки уже сделана с июня. Мерь, прежде чем чинить.
8. **Старый комментарий — не текущее состояние.** Проза в теле сторожа часто
   описывает, ПОЧЕМУ что-то добавили, а не что сломано сейчас.
9. `git commit -m` с кириллицей ломается — **только `-F <файл>`**.
10. `npm audit fix --force` — **ЗАПРЕЩЕНО**. Пароли — **никогда не спрашивать**.
11. **Два раунда ревью РАЗНЫМИ линзами** на всё, что трогает RLS, гранты,
    `SECURITY DEFINER`, триггеры, авторизацию, service-role код и прод-миграции.
    Вывод субагента **проверяй лично**.
12. **Накатил — смёржил.** Гейт симметричен: строка леджера без файла в `main`
    ломает КАЖДУЮ прод-сборку. Окно между накатом и мержем — красное.
13. **Живую проверку прода из контейнера не гонять** (домен не в allowlist) —
    только с машины владельца.
