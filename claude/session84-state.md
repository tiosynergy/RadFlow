## Уроки сессии

* **Фикс безопасности — тоже новый код.** Первая версия `safeRedirectPath` проверяла ВХОД, а
  возвращала нормализованный путь — и сама создала редирект через dot-сегменты, которого при
  старом выражении не было. Проверять ВЫХОД функции-санитайзера, а не только вход; инвариант на
  сгенерированном корпусе вместо списка примеров.
* **Проба отказа должна назвать объект.** «Поймали 42501» — не доказательство: функция INVOKER с
  EXECUTE падает 42501 на ЧУЖОЙ таблице, отказ `SET ROLE` — тоже 42501. Проверять перемикание
  роли и текст отказа; у пробы обязана быть красная базовая линия (falsify с грантом).
* **`echo X=%ERRORLEVEL%>> file` в .bat** при однозначном коде даёт `0>>` — перенаправление
  дескриптора 0, строка в лог не попадает (так было и в с83). Писать `>>file echo X=%ERRORLEVEL%`
  или с пробелом перед `>>`. И `if exist A del A & start …` — всё после `&` уходит в тело `if`.
* **Через мост DC инлайн-PowerShell теряет `$`** (`$_`, `$b` вырезаются) — сложные пробы писать
  файлом `.ps1` через `write_file` и запускать `-File`.
* **`auth.admin.updateUserById(id, { password })` завершает ВСЕ сессии человека** — свой пароль
  через admin-путь не менять никогда (оператор теряет сессию вместе с показанным паролем); свой —
  только `auth.updateUser` через собственную сессию.
* **SQL Editor Supabase выполняет ВСЁ содержимое вкладки одним Run и показывает результат только
  последнего оператора** — запрос, показывающий секрет, и запрос, удаляющий его, никогда не давать
  в одном сообщении/блоке; удаление — отдельным шагом после подтверждения «сохранил».
* **Состояние настройки — из замера, не из головы.** В с84-B я написал «Secure email change обязан
  оставаться включённым», а ToDo П-6 с 15.09 говорит «выкл»: фраза про ЖЕЛАЕМОЕ состояние читалась как
  описание ТЕКУЩЕГО и прятала, что тумблеры выключены. Перед словами «остаётся / уже включено» — сверка с
  ToDo и замером; нового пункта ToDo не заводить, пока не проверено, что его нет под другим номером.
  И при исправлении не уходить в обратную крайность: первая редакция с84-C написала «путь через почту
  открыт уже сегодня» про НЕ замеренный T9 — та же ошибка с другим знаком (поймало ревью диффа).
* **Независимая сверка инструкции по коду окупается сразу:** 12 находок; шаги, которые падали бы как
