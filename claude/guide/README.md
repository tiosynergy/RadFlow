# Исходники инструкции пользователя

Собранный файл — [`../../docs/USER_GUIDE.html`](../../docs/USER_GUIDE.html): автономный
HTML на украинском, с картинками внутри (base64), без единой внешней ссылки. Открывается
двойным кликом без сети, печатается (`@media print` прячет оглавление), тёмная тема —
по системной настройке.

**Редактировать надо части, а не собранный HTML** — сборка его перезаписывает.

| Файл | Что внутри |
|---|---|
| `part1.html` | Шапка, весь CSS, оглавление, разделы «Про цю інструкцію», 1 (роли), 2 (начало работы), 3 (мастер настройки) |
| `part2.html` | Разделы 4 (администратор) и 5 (регистратор) |
| `part3.html` | Разделы 6 (радиолог), 7 (направитель), 8 (CEO), 9 (общие инструменты), 10 (FAQ), 11 (словарь), закрывающие теги |
| `guide-shots.mjs` | Рисует 8 макетов экранов настоящим CSS проекта на **вымышленных** пациентах |
| `optimize.py` | Сжимает макеты (1.5×, 48 цветов) — от этого напрямую зависит вес HTML |
| `assemble.py` | Склеивает части, подставляет картинки вместо `{{IMG:name}}`, оборачивает таблицы |

## Правка текста (браузер не нужен)

```
python claude/guide/assemble.py
```

Если папки `shots/` нет (она в `.gitignore`), сборка берёт те же картинки из предыдущей
версии `docs/USER_GUIDE.html` — они помечены там `data-shot="<имя>"`. Поэтому текст можно
править на любой машине, где есть Python.

## Перерисовать макеты

```
npm i -D playwright && npx playwright install chromium
node claude/guide/guide-shots.mjs     # shots/<name>.png, 2×
python claude/guide/optimize.py       # shots/<name>.opt.png
python claude/guide/assemble.py
```

Выноски (синие кружки на полях макетов) расставлены вручную координатами в
`guide-shots.mjs` — меняя разметку макета, проверь, что кружок не уехал за край и что
нумерация всё ещё совпадает с `<ol class="legend">` в соответствующей части.

## Правила

- **Никаких настоящих пациентов.** Все ФИО, телефоны, даты и врачи в макетах выдуманы;
  прод-данные в документ не попадают ни при каких условиях.
- **Никаких внешних ресурсов** — ни шрифтов, ни CDN, ни `<script>`: файл должен открываться
  без сети. После сборки проверь: `grep -o 'src="[^"]*"' docs/USER_GUIDE.html` должен дать
  только `data:` — и ничего больше.
- **Формулировки кнопок — как в коде.** Тексты в инструкции взяты из компонентов дословно;
  меняя надпись в UI, поправь и здесь, иначе документ начнёт врать.
