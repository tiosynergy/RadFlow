## 4. Правила, которые нарушать нельзя

**Безопасность и данные**

* Секреты и ПИИ **никуда**: ни в отчёт, ни в лог, ни в промпт субагента.
* Прод-данные — только по **явному списку id с до-образами**; до-образ
  редактируется, если строка несёт секреты.
* **Дев и прод — ОДНА база.** `npm audit fix --force` **запрещён**.
* **Никогда не спрашивай пароли** и не вводи их: владелец логинится сам.

**Миграции и сторож**

* Всё, что трогает RLS, гранты, `SECURITY DEFINER`, триггеры, авторизацию,
  service-role код или прод-миграции — **два независимых раунда ревью РАЗНЫМИ
  линзами**, и каждый вывод субагента проверяй лично.
* **«Сухой» прогон БЕЗ маркера отката — это НАКАТ.** Файлы миграций несут
  собственный `COMMIT`.
* Откат, проверенный внутри той же транзакции, не доказывает ничего — бери md5
  **отдельным запросом**.
* **«Успех» — не доказательство.** После каждого наката проверяй ЗАПРОСОМ.
* **Накатил — смёржил.** Гейт симметричен: строка в леджере без файла в `main`
  ломает каждую прод-сборку, и файл без строки — тоже.
* Никогда не трогай дерево, пока идёт стенд.

**Инструменты (выстрадано)**

* `git commit -m` с кириллицей ломается — **только `-F` из файла**.
* `git add -A` **запрещён** — перечисляй пути явно
  (`docs/audit/INCIDENT-2026-09-13-git-add-all.md`).
* PowerShell через мост съедает `$_` и падает на кириллице в `.ps1` без BOM —
  пиши скрипты латиницей, а в однострочниках `$_` не используй.
* `timeout` через мост — no-op; используй `Start-Sleep`/`sleep` и печатай время
  пробуждения. `read_process_output` возвращает управление раньше таймаута —
  **не считай опросы минутами**.
* Живую проверку **нельзя** гонять из контейнера (домен не в allowlist) —
  только машина владельца.
* Состояние после `element.click()` читай **следующим** вызовом инструмента:
  React не успевает перерисоваться внутри того же.

**Метод**

* Вчерашний документ — гипотеза о сегодняшнем состоянии, а не факт. В с73 на
  этом споткнулись дважды: «зеркало Google мертво» оказалось неправдой, а
  строка «открыто» в журнале три дня носила закрытые пункты.
* Список, снятый сканером или регексом, — гипотеза. Подтверждай чтением.
* Расхождение «документация мягче замера» опаснее обратного: план строят по
  документации.
* Прежде чем объявить что-то ждущим решения владельца — поищи это в
  `docs/audit/DECISIONS-*`. В с73 половина пункта 4.2 оказалась решённой ещё
  в с68.
