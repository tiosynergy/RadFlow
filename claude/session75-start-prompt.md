## 4. Правила (нарушать нельзя)

**Безопасность и данные.** Секреты и ПИИ никуда. Прод-данные — только по явному
списку id с до-образами. **Dev и прод — одна база.** `npm audit fix --force`
запрещён. Пароли не спрашивать и не вводить.

**Миграции и сторож.** Всё, что трогает RLS/гранты/DEFINER/триггеры/сторожа —
два раунда ревью разными линзами + раунд по фиксам; каждый вывод субагента
проверяй лично. «Сухой» прогон без маркера отката — это НАКАТ. Проверка отката
внутри той же транзакции не доказывает ничего. После наката — проверка
ЗАПРОСОМ. **Накатил — смёржил.** Не трогай дерево, пока идёт стенд.

**Выстрадано в с74:**

* **Ревизия стендов, запущенная через мост, может умереть молча** (с74:
  процесс исчез на старте `falsify-0192-tz`, осталась метка
  `.falsify-all.running`). Порядок при смерти: `git status` → мутаций нет →
  снять метку → доганять остаток. **Надёжнее — полная ревизия в облачном
  контейнере** на чистом клоне запушенной ветки (решение владельца 13.09,
  п. 4-бис плана): `git clone`, `npm ci` (~16 с), `node scripts/falsify-all.mjs`.
  Пуш из контейнера невозможен (прокси не даёт кредов) — пушит машина.
* **MCP `execute_sql` не возвращает `raise notice`** — успех наката делай
  видимым отдельным `select` в конце того же запроса.
* **Тег блока в dryrun и apply должен различаться** (`$dryrun$`/`$apply$`).
* `privilegeSurface.test.ts` ищет заголовок перепечатки `indexOf` БЕЗ якоря —
  первое вхождение фразы должно быть заголовком.
* `gcalSyncOverdue.test.ts` пинит `EXPECTED_STANDS = 40` — новый стенд тянет
  правку чужого теста; разовая фальсификация с протоколом — законная форма.

**Инструменты.** `git commit -m` с кириллицей ломается — только `-F`.
`git add -A` запрещён. PowerShell через мост: латиница в скриптах, без `$_` в
однострочниках, логи через `cmd /c "… > file 2>&1"`. Живую проверку из
контейнера не гонять (домен не в allowlist).
