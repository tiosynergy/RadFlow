## 4. Правила (нарушать нельзя)

**Безопасность и данные.** Секреты и ПИИ никуда (ни в отчёт, ни в лог, ни в
промпт субагента). Прод-данные — только по явному списку id с до-образами.
**Dev и прод — одна база.** `npm audit fix --force` запрещён. Пароли не
спрашивать и не вводить: владелец логинится сам.

**Миграции и сторож.** Всё, что трогает RLS/гранты/DEFINER/триггеры/
авторизацию/service-role/сторожа — два раунда ревью разными линзами + раунд по
фиксам; каждый вывод субагента проверяй лично. «Сухой» прогон без маркера
отката — это НАКАТ. Проверка отката внутри той же транзакции не доказывает
ничего. «Успех» — не доказательство: после наката — проверка ЗАПРОСОМ.
**Накатил — смёржил.** Не трогай дерево, пока идёт стенд. Отрезок «накат →
`db:gate`» не должен пересекать крон `invariants` в 03:50 UTC.

**Выстрадано в с74 (0201):**

* **Цена ратчета №26.** Любое членство с клиентской стороной, ACL схемы/базы
  для клиента или PUBLIC, default ACL, настройка или атрибут клиентской роли —
  перепечатка сторожа. Обновление платформы Supabase или расширение, включённое
  в дашборде, покраснит ночной крон — разобраться и перепечатать, а не глушить.
  `AGENTS.md`, блок «ЦЕНА РАТЧЕТА №26».
* **PL/pgSQL: переменная-запись с именем, совпадающим с алиасом в SQL** (`r
  record` + `from pg_roles r`) — `55000 record "r" is not assigned yet` в
  рантайме, не при компиляции. В DO-блоках — только `v_*`.
* **Пуш из контейнера невозможен** (`tiosynergy/RadFlow` не в наборе
  репозиториев сессии). Файлы на машину — через мост; `write_file` Desktop
  Commander **декодирует юникод-эскейпы (обратный слэш + u)** — правки с
  обратными слэшами передавай как
  node-скрипт с base64 (`Buffer.from(s,"base64")`). Каждый перенос сверяй
  `git hash-object` и деревом коммита (`HEAD^{tree}`) на обеих сторонах.
* **Полная ревизия стендов — в контейнере** (40/40 с74); через мост она
  однажды умерла молча (метка `.falsify-all.running`).
* **Эвристика якорей стендов слепа** — генератор 0201 использует JS-лексер
  литералов (122); переиспользуй его.
* **Чужой сторож зеленит стенд** (класс N20): новая проверка может выполнить
  утверждение старого теста за счёт своего кода (`falsify-0166` N20 и
  `a.grantee = 0` из №26). Пины — точными предикатами, не `toContain` фрагмента.
* **Прод может расходиться с файлом миграции по комментариям** (0195 ушла
  черновиком) — перед пином тела сверяй md5 из файла и из прода.
* **MCP `execute_sql` не возвращает `raise notice`** — успех делай видимым
  отдельным `select`; у MCP бывают окна обслуживания (с74: до 21:45 UTC).
* Тег блока в dryrun и apply различается (`$dryrun$`/`$apply$`).

**Инструменты.** `git commit -m` с кириллицей ломается — только `-F`.
`git add -A` запрещён. PowerShell через мост: латиница в скриптах, без `$_` в
однострочниках; `cmd` надёжнее для git/node. Живую проверку из контейнера не
гонять (домен не в allowlist) — штамп деплоя `curl` с машины владельца.
