## 3. Правила (нарушать нельзя)

**Безопасность и данные.** Секреты и ПИИ никуда (ни в отчёт, ни в лог, ни в
промпт субагента). Прод-данные — только по явному списку id с до-образами.
**Dev и прод — одна база.** `npm audit fix --force` запрещён. Пароли не
спрашивать и не вводить: владелец логинится сам.

**Миграции и сторож.** Всё, что трогает RLS/гранты/DEFINER/триггеры/
авторизацию/service-role/сторожа — два раунда ревью разными линзами + раунд по
фиксам; каждый вывод субагента проверяй лично. «Сухой» прогон без маркера
отката — это НАКАТ. Проверка отката внутри той же транзакции не доказывает
ничего. «Успех» — не доказательство: после наката — проверка ЗАПРОСОМ.
**Накатил — смёржил.** Не трогай дерево, пока идёт стенд. Отрезок «накат →
`db:gate`» не должен пересекать крон `invariants` в 03:50 UTC. ⚠️ **После
`db:gate` генератор перепечатки (`build-02xx-reprint.mjs`) не запускать** —
перезапишет файл, чей md5 уже в леджере.

**Выстрадано в с75 (0202):**

* **`"char"`-колонки каталога (`prokind`, `provolatile`, `relkind`…) в
  конкатенации — только через `::text`:** `text || "char"` неоднозначен
  (`42725 operator is not unique`). Ни tsc, ни pglast, ни две линзы ревью этого
  не видят — видит только сухой прогон на реальном PG. Поэтому сухой прогон —
  не формальность.
* **Отправленный через MCP текст доказывай diff-ом по журналу сессии**
  (`/root/.claude/projects/-home-claude/*.jsonl`, `tool_use` → `execute_sql`):
  «побайтово = файл» перестаёт быть заявлением. В с75 все прогоны так сверены.
* **Замер в сухом прогоне зависит от данных** (нужен `scheduled` в будущем;
  посевная неделя кончилась 15.09 → `-3`). Fallback — отдельный откаченный
  блок на последнем прошлом `scheduled`; картина та же.
* **Зонд внешнего API не должен просить больше, чем scope приложения:**
  `calendars.get` требовал `calendar.readonly`, токен зеркала его не имеет —
  шаг, который не мог пройти никогда, красил вердикт. Информационные шаги —
  вне вердикта, с объяснением.
* **Google канонизирует `Europe/Kyiv` → `Europe/Kiev` в ответе.** Для зеркала
  безразлично (отпечаток без зоны), но любой будущий код, сравнивающий
  `timeZone` из ответа с тем, что послали, обязан это учитывать.
* **Компонент, объявленный внутри рендера родителя, ремонтируется каждый
  кадр** — для кнопки это потеря фокуса после Enter (HIGH ревью WCAG). Правило
  уже было в QueueBoard (`CancelledRow`); пин — `wcagHigh.test.ts`.
* **«max 19 с» одного вызова из 19 174** — сначала `cron.job_run_details` с
  датой и `pg_stat_statements` (sd сходится на одном вызове, blks_read 0), потом
  гипотезы: минута совпала с нашим же DDL.
* **Контейнерная ветка с локальной историей даёт ложные конфликты при merge
  origin/dev** (одинаковые деревья, разные коммиты) — для доков делай worktree
  от настоящего `origin/<branch>` и мержь туда. `git fetch` из контейнера
  работает, push — нет.

**Выстрадано в с74 (0201)** — без изменений: цена ратчета №26 (`AGENTS.md`),
`r record` vs алиас `r` → только `v_*`, пуш из контейнера невозможен (перенос

**Инструменты.** `git commit -m` с кириллицей ломается — только `-F` из
файла. `git add -A` запрещён. Через мост — `cmd`, не PowerShell; `findstr` с
кириллицей не работает (кодировка), в цепочках с `&&` не использовать. Живую
проверку из контейнера не гонять (домен не в allowlist) — штамп деплоя `curl`
с машины владельца. Декодер патчей на машине: `node .git\decode_any.js <name>`
(читает `.git\<name>.b64`, пишет `.git\<name>.patch`, печатает md5).
