## Уроки сессии

* **Ignore прячет мусор и от глаз:** правила `/*.log`, `/*.done`, `/falsify-*.md` спасали git, но
  за 30+ сессий в корне скопилось 96 файлов, а папки доставки (без правила) висели в VS Code
  как «незакоммиченные изменения». Ignore без процедуры уборки — половина решения.
* **Двойник должен ошибаться так же, как оригинал.** `.single()` на 0 строк в фикстуре —
  `error: null`, у postgrest-js — `PGRST116`; ветка «не логировать PGRST116» была
  непроверяемой, пока тест не подал настоящую форму ошибки (нашло ревью, мутацией).
* **«Мы сами себя не фреймим» — проверять по документам процесса, а не только по коду:**
  в коде iframe нет, но AGENTS.md описывает same-origin iframe для проверки узких экранов —
  `'none'` молча сломал бы её.
* **Заявление о дыре — по замеру механизма:** «консоль можно встроить в чужой фрейм» было
  верно для страницы, но не для СЕССИИ — cookie `SameSite=Lax`; заголовки — вторая линия.
* **Сканер порядка, который смотрит лишь после якоря, пропускает перенос ДО якоря** — искать
  по всему телу и исключать только законные предшественники (гейты до разбора тела).
