# RadFlow — статический переаудит WCAG 2.2 AA (15.09.2026)

План аудита, пункт 4.4. Живой проверки с клавиатурой и скринридером в этой работе не было (чек-лист для неё — в разделе 4).

## 1. Область и метод

**Что проверялось.** Ветка `origin/dev`, коммит `ede9b8c` (15.09.2026), read-only клон. В охвате 64 компонента `components/*.tsx`, 19 страниц `app/**/page.tsx`, `lib/useModalA11y.ts`, `lib/modalTrapStack.ts`, стили `styles/prototype/{radflow,radflow-screens,radflow-wizard,radiologist}.css` и `components/register.css`.

**Как проверялось.**
- Код читался вручную по каждому критерию из задания.
- Две вспомогательные эвристики на node нашли кандидатов, каждый из них потом проверен глазами:
  - поля ввода без `<label>`, `aria-label` или `htmlFor`;
  - кнопки, у которых вместо текста только глиф, без `aria-label`.
- Запущен `node scripts/contrast-audit.mjs`. Скрипт использует только `fs`, сеть и БД не нужны. Код выхода 0, итог «усі пари проходять пороги WCAG 2.1 AA». Скрипт проверяет лишь синие роли, `--text-secondary` и позиции «непрочитано»: красный текст, фолбэки неопределённых токенов и границы полей он **не** покрывает. Эти пары досчитаны по той же формуле WCAG, цифры приведены в W-4 и W-15.
- Перед аудитом прочитаны прошлые работы: PR-U8, PR-U30, AUDIT_2026-07-11 (пп. 15, 17, 18), RF-06 и его перемер, UX_AUDIT_V2_STATUS, PRODUCT_OVERVIEW §4.12. Уже закрытое повторно не заявляется (см. раздел 3).
- Рабочие экраны персонала **не** задокументированы как «только для десктопа». Наоборот, есть адаптивная работа: шторка меню ≤480px, карточная раскладка строк, `pointer: coarse`. Поэтому 1.4.10 в охвате.
- ⚠️ Лично перепроверены автором сессии (с74) до внесения в репозиторий: W-1 (`radflow.css:543-546` — свёрнутость только через `grid-template-rows: 0fr` + `overflow: hidden`) и W-3 (`CallListBoard.tsx:94-97` — один ☎ с цветом по статусу, глифы `CL_META.icon` не выводятся).

**Что статический анализ установить НЕ может:**
- что фактически произносят NVDA/JAWS/VoiceOver с украинским голосом. Сюда относится, читается ли `title` как описание, как озвучиваются глифы ♂ ✓ ☎ ⏻ и работают ли live-регионы, у которых роль меняется на лету;
- реальную раскладку при масштабе 200% и 400% и реальные размеры целей: ширины ниже посчитаны из CSS без учёта полосы прокрутки;
- видимость кольца фокуса поверх реального рендера, в том числе обрезку предками с `overflow: hidden`;
- куда уходит фокус после перерисовки из-за realtime, когда строка переезжает в другую панель или удаляется;
- доступность нативных `<input type="date/time">` в конкретном браузере и поведение режима Windows High Contrast.

Там, где вывод зависит от этого, стоит **needs-live-check**.
