## 5. Дія B — відкат (він же тест гілки DELETE)

Той самий діалог → «Закревського, 9» → «Працює» → «✓ Зберегти графік».
Рядок `schedule_overrides` зник (`overrides_17 = 0`), а маркер **не
задублювався**: той самий `id ae5a3d26…` лишився один, але

```
event_type  schedule.override_changed → schedule.override_cleared
details     {"cleared": false} → {"cleared": true}
created_at  19:00:24 (оновився)
```

Тобто якір `(recipient, entity, field_scope, subject_date)` тримає рівно одну
крапку на одну дату та кабінет, а гілка DELETE в `tg_change_markers_sched_override`
рахує «новини дня» по полях `old`, а не по `tg_op` — саме як писали в 0184.
Підпис для цього стану: **«особливий графік кабінету на 17.09 знято»**.
